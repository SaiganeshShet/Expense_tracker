# Expense tracker

A small React and Vite expense tracker for adding, filtering, and removing expenses.

## Requirements

- Node.js 20 or newer
- npm

## Getting started

```sh
npm install
npm run dev
```

## Verification

```sh
npm run lint
npm run test:run
npm run test:coverage
npm run build
```

For browser tests, start the dev server with `npm run dev` in one terminal, then run `npm run cy:run` in another. Use `npm run cy:open` for the interactive Cypress runner.
